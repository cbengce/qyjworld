# Search and enquiry measurement

The owner dashboard is `/zh/admin/discovery` or `/en/admin/discovery`. Only super admins and managers can open it. It uses actual request records and current public menu/store data. It does not invent traffic data or attribute every group request to search.

## Search Console

Use the existing verified qyjworld.com property if one exists; do not create a duplicate just because this workspace has no access. DNS verification needs no website tag. For HTML verification only, set `GOOGLE_SITE_VERIFICATION` to the exact token Google issues in the production Vercel environment, redeploy, then complete Google's verification. Configuring the tag is not verification itself.

Submit the existing `https://qyjworld.com/sitemap.xml` in the verified property. Inspect representative English/Chinese menu details, group-orders, guides and articles. Record submitted canonical, Google-selected canonical, crawl status and actual indexing status. Sitemap presence and HTTP 200 do not prove indexing.

Compare actual impressions, clicks, CTR and average position by landing page, locale and relevant query groups. Do not promise a fixed indexing timeframe. Google AI features are included in Search Console's Web performance; that report does not separately identify every AI citation.

## Group requests

Current dashboard counts: requests received in the past rolling 30 days, with current requested/quoted/confirmed/fulfilled/cancelled status. Confirmed/fulfilled are operational states, not payment receipts. Search attribution is unavailable until a connected analytics source can substantiate it. Never record names, emails, phone numbers or form notes in analytics events.

## Product and local records

Use outlet menu settings for regular/member prices and availability; product editors for approved bilingual descriptions; store editors for address, phone and normal/exception hours. Do not enter old poster prices as current prices without approval.

Review Business Profile against the same managed store data, including special hours, website/menu links and original store photos. External account access is needed before updating or verifying it. Invite only authentic voluntary reviews; no fabricated reviews or promised ranking outcomes. External outreach/public posts require the owner's separate sending instructions.
