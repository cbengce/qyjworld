# User Acceptance Testing Checklist

- Home page displays logo placeholder, Born to Ascend, Sparkling Tea Reimagined, menu CTA and membership CTA.
- Menu page clearly marks sample items and does not present fake final prices.
- Membership page states SGD 39.90 and 60 days from activation.
- Register form collects name, mobile, email, password, optional DOB, optional referral code and consent checkboxes.
- Registration creates pending membership only.
- Member login works.
- Member dashboard displays membership validity, points balance, member number, QR code and referral link.
- Expired membership message is clear.
- Admin can search members.
- Admin can activate membership.
- Admin can add, deduct and reverse points through ledger entries.
- Admin can export CSV reports.
- Public legal pages are present and marked for legal review.
- Mobile layouts are readable and buttons are easy to tap.
