# QING YUN JIAN Editorial Knowledge Base

This directory is the version-controlled source of truth for QING YUN JIAN brand and editorial work.

Start with [00_READ_FIRST.md](./00_READ_FIRST.md). Before drafting or revising content, consult the Fact Register, Editorial Voice, Legal and Claims Standard, and any topic-specific record. Templates are in `knowledge/templates/`.

The knowledge base records what is verified, what is an approved interpretation, and what still requires founder, product-team, expert, or legal input. It must never be used to turn an assumption into a fact.

## Directory map

- `00_READ_FIRST.md`: mandatory contributor rules
- `01_BRAND_FOUNDATION.md`: verified foundation and approved interpretation
- `02_FOUNDER_STORY.md`: founder interview framework
- `03_EARLY_BELIEVERS_VISION.md`: cautious strategic framework

- `06_TEA_LAB.md`: first-hand testing standard
- `07_EDITORIAL_VOICE.md`: voice and language rules
- `08_SEO_AND_EEAT_STANDARD.md`: content-type quality requirements
- `09_LEGAL_AND_CLAIMS_STANDARD.md`: claims and review controls
- `10_EDITORIAL_WORKFLOW.md`: drafting and publication workflow
- `11_FACT_REGISTER.md`: controlled facts
- `12_SOURCE_REGISTER.md`: source-management framework
- `13_CONTENT_AUDIT_STANDARD.md`: publication-readiness audit
- `current-content-review-register.md`: current generated-content status
